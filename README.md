PathMakers

PathMakers is a travel platform designed to simplify trip planning and booking.
Our platform allows users to explore and purchase travel packages, while leveraging AI to provide personalized travel consultations.

Live Demo

You can see the platform live here: [PathMakers Web App](https://pathmakers-web-app.onrender.com)

Project Overview

This project was developed by a team of two. It consists of:

Web platform: Built with React for managing trips, bookings, and user interactions.

Mobile app: Developed in React Native for users to browse and purchase travel packages.

Backend: Node.js server with MongoDB for storing trips, users, and orders.

AI integration: LLaMA AI is used for basic travel consultation, helping users plan trips based on preferences.

UX/UI design: Implemented design techniques and principles learned during our studies to enhance user experience and interface usability.

Features

Browse and book travel packages through the mobile app or web platform.

AI-based consultation for trip suggestions.

Real-time data storage and retrieval using MongoDB.

User-friendly interface with UX/UI principles applied.

Full-stack solution connecting frontend, backend, and database seamlessly.

Tech Stack

Frontend: React, React Native

Backend: Node.js, Express

Database: MongoDB

AI: LLaMA AI for travel consultation (huggingface)

Design: UX/UI techniques applied for optimal user experience
